# Dr. Rafael Costa | Site Médico Profissional

Site institucional médico desenvolvido com foco em credibilidade, confiança e conversão de visitas em pacientes. A proposta visual é moderna, elegante, minimalista e 100% responsiva, com destaque para o médico como marca principal.

## Visão geral

Este projeto foi criado para representar uma clínica ou consultório médico com identidade profissional e acolhedora, enfatizando:

- apresentação do profissional e sua especialidade
- áreas de atuação com foco em neurologia e saúde do paciente
- tratamentos e procedimentos
- conteúdo educativo e artigos
- contato, WhatsApp, localização e formulário de agendamento
- performance e experiência de usuário em dispositivos móveis

## Objetivo

Criar uma presença online que transmita autoridade médica, gere confiança e facilite o agendamento de consultas, mantendo uma aparência sofisticada e sofisticada, sem parecer uma grande clínica ou hospital.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive design
- Integração visual com redes sociais e WhatsApp
- Mapa embutido via iframe do Google Maps

## Como executar localmente

1. Acesse a pasta do projeto
2. Abra o arquivo `index.html` diretamente no navegador
3. Ou execute um servidor local, por exemplo:

```bash
cd "c:/Users/DELL/Arquivos da Triple Ten/projeto medicina"
python -m http.server 8000
```

Em seguida, abra no navegador:

```bash
http://localhost:8000
```
